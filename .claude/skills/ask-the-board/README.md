# Ask the Board — Portable Copy

This folder is everything the skill needs. Nothing lives anywhere else. Copy this whole folder and it works.

## What's inside

| File | What it's for |
|---|---|
| `SKILL.md` | The main instructions — how the board works, the 3-round format, the rules. Read this first. |
| `advisors/*.md` | One file per advisor (Cal Newport, Morgan Housel, Jocko Willink, Steve Wozniak, Sara Blakely). Their real quotes, frameworks, and voice. |
| `advisors/_TEMPLATE.md` | Blank template for adding a new advisor later. |
| `memory/profile.md` | What the board knows about Tyler — how he wants advice delivered, his situation. |
| `memory/decisions.md` | Log of past questions and what the board recommended. |
| `references/adding-an-advisor.md` | Steps for vetting and adding a new advisor. |
| `references/vetting-filter.md` | The 5-point filter used to check if someone belongs on the board. |

## How to use this in another AI tool

1. **Paste `SKILL.md` as your system prompt / custom instructions.** This tells the AI how the board behaves.
2. **Attach or paste the 5 advisor files** (`advisors/cal-newport.md`, etc.) as reference material — either upload them if the tool supports file attachments, or paste their contents into the same system prompt/project instructions.
3. **Attach `memory/profile.md` and `memory/decisions.md`** the same way, so the board still knows Tyler's preferences and history.
4. Ask your question. If the tool supports it, ask the AI to update `memory/decisions.md` and `memory/profile.md` after each session, same as this skill does — just paste the updated text back in, or re-upload the file.

No app-specific formatting, no special file types — just plain markdown text. Any AI tool that accepts a system prompt and reference documents can run this.

## Keeping it backed up

This whole folder is also zipped as `board-of-advisors-portable.zip` in the same location, for easy copying or storage elsewhere (email, cloud drive, USB, etc.). If you edit any of the markdown files later, re-zip the folder so the backup stays current.
